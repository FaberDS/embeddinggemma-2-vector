# Project instructions

## Agent skills

Project skills live in `.agents/skills/`. Read the relevant `SKILL.md` before
using a skill. Sources and pinned revisions are listed in
`.agents/skills/README.md`.

### Issue tracker

Use Linear's **Personal Embedding Project** in team **Schuele (`SCH`)**.
Read `docs/agents/issue-tracker.md` before issue operations and use the
project's `linear` skill with the connected Linear tools.

### Open decisions

Ask unresolved questions interactively. Do not invent requirements, label
vocabulary, priorities, assignees, cycles, due dates, or documentation layouts.
Reuse choices already supplied by the user and facts verified from the repo
or Linear.
